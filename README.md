# SQL-exercise


00 📖 Overview

Welcome to my SQL Exercises repository! This repository contains a collection of SQL practice exercises that demonstrate my understanding of fundamental and intermediate SQL concepts. The exercises are organized into different topics to provide a structured learning experience and showcase practical problem-solving skills using SQL.

The goal of this repository is to strengthen SQL proficiency through hands-on examples covering querying, data manipulation, joins, aggregate functions, date functions, and more.
